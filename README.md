# Python_DA-_Assignment_1
# Python Data Analysis Fundamentals – NumPy & Pandas

## 📌 Project Overview

This project demonstrates the fundamentals of Python for Data Analysis using two popular Python libraries: **NumPy** and **Pandas**.

The notebook explores how to create and manipulate arrays, work with structured data, perform data filtering, calculate statistics, and analyze transaction records.

It is designed as a practical learning exercise for beginners who want to develop their Python programming and data analysis skills.

## 🎯 Objectives

- Understand NumPy arrays and their properties.
- Perform mathematical and statistical operations.
- Learn Pandas Series and DataFrames.
- Practice data selection and indexing.
- Filter datasets using conditional statements.
- Perform grouping and aggregation.
- Modify and clean datasets using Pandas.

## 📚 Topics Covered

### 1. NumPy – Numerical Computing

- Creating NumPy arrays.
- Checking array shape, size and data types.
- Temperature conversion (Celsius to Fahrenheit).
- Maximum, minimum and mean calculations.
- Array slicing and indexing.
- Working with multidimensional arrays.

### 2. Pandas – Series

- Creating Pandas Series.
- Label-based indexing using `loc`.
- Position-based indexing using `iloc`.
- Conditional filtering.
- Updating and deleting records.
- Basic calculations using Series.

### 3. Pandas – DataFrames

A sample transaction dataset is created with the following columns:

- TransactionID
- ProductCategory
- Region
- Amount

**DataFrame operations covered:**

- Displaying the first and last records.
- Checking dataset shape and columns.
- Understanding data types.
- Selecting specific columns.
- Filtering transactions by region and amount.
- Counting product categories.
- Identifying unique regions.
- Calculating average transaction amounts by region.
- Updating transaction values.
- Creating discount calculations.
- Removing records and columns.
